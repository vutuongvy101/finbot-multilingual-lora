# Adapter artifacts

LoRA adapter weights, eval metrics, and training metadata are **not** stored in this repository. Download from Hugging Face Hub:

**[bibbbu/lora-qwen25-1p5b-finbot-v2](https://huggingface.co/bibbbu/lora-qwen25-1p5b-finbot-v2)**

For local override, set `FINBOT_ADAPTER_PATH` in `.env` to a directory containing the downloaded adapter files.
